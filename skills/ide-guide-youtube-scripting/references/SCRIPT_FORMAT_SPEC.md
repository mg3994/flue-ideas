# IDE Guide YouTube Script Specification

This specification provides the markdown layout used for generated YouTube scripts in the IDE Guide project.

```markdown

**Channel**: [IDE Guide](https://www.youtube.com/@IDEguide)  
**Blog Companion**: [IDE Guide Blog](https://ideguide.blogspot.com/)  
**Target Duration**: 10:30  
**Focus Tools**: [IDE Names]
```
