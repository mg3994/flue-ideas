# IDE Guide YouTube Scripting Skill

This skill defines the format and structural rules for producing video scripts for the **IDE Guide** YouTube channel (`https://www.youtube.com/@IDEguide`).

## Core Principles

1. **Mandatory Non-Affiliation Disclaimer**: Every video script MUST feature a verbal disclaimer within the first 60 seconds and state it explicitly in the video metadata description.
2. **Synchronized Dual-Column Flow**: Visual cues (what appears on screen, B-roll, UI demos, benchmarks) must accompany every line of spoken dialogue.
3. **Structured Pacing**: Target duration between 8 and 12 minutes, divided into clear chapters with exact timestamp targets.
4. **Actionable Technical Comparison**: Ground evaluations in factual documentation, performance benchmarks, real developer workflow trade-offs, and community consensus.

## Mandatory Disclaimer Text

> "Disclaimer: We are not affiliated with, sponsored by, or endorsed by any of the IDE developers, companies, or organizations mentioned. The guides, reviews, and tutorials provided are based solely on publicly available documentation, web resources, community feedback, and independent testing. All trademarks and registered trademarks are the property of their respective owners."

## Standard Video Script Structure

Every video script consists of:

1. **Header Metadata**: Episode number, video title, target duration, focus IDE(s), target audience.
2. **Video Intro & Hook (0:00 - 0:45)**: Rapid demonstration of the key developer pain point or new feature.
3. **Mandatory Disclaimer Spoken Segment (0:45 - 1:00)**: Host or voiceover delivers the non-affiliation disclaimer clearly.
4. **Architectural & Ecosystem Deep-Dive (1:00 - 3:00)**: Memory model, language server protocol, extensions engine, native vs. webview.
5. **Hands-On Feature Walkthrough & Workflow Test (3:00 - 7:00)**: Real-world coding examples, navigation, debugging, refactoring, and AI assist capabilities.
6. **Comparison Matrix & Performance Analysis (7:00 - 9:00)**: RAM usage, cold start times, indexing speed, licensing/pricing.
7. **Pros & Cons Summary (9:00 - 10:15)**: Balanced analysis highlighting strengths and limitations.
8. **Final Verdict & Who Should Use It (10:15 - 11:00)**: Clear developer profile recommendations.
9. **Outro & Channel Links (11:00 - 11:30)**: Call-to-action to subscribe to `https://www.youtube.com/@IDEguide` and read the deep-dive AMP article on `https://ideguide.blogspot.com/`.
10. **Publishing Metadata**: SEO YouTube Title, Description (with timestamps, links, and disclaimer), Search Tags, and Pinned Comment.
